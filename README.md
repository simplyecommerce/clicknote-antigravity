# ClickNote for Google Antigravity

ClickNote is a website feedback tool for web agencies. Clients click directly on the part of a website they mean and leave a note, without creating an account or installing a browser extension. Every note records the page, the exact element (its CSS selector and XPath), a screenshot, and the browser and device it was left on.

This plugin connects Antigravity to your ClickNote workspace, so your agent can work through that feedback in your codebase: find the open notes on a project, read a note with everything it captured about the element, go to the file that element comes from, make the change, then mark the note done and leave an internal note for your team.

## What you need

- A ClickNote workspace. You can start a 14-day free trial at [clicknote.io](https://clicknote.io).
- Nothing else. There's no key to make: Antigravity signs in to ClickNote for you.

## Connecting

1. Install the plugin.
2. Under **Customizations**, **Installed**, **MCP Servers**, select **Authenticate** beside ClickNote.
3. Antigravity opens ClickNote in your browser. Sign in if you're asked to, choose how much Antigravity may do and press **Allow**.
4. Copy the authorisation code Antigravity's page shows, paste it into **Enter authorization code** and click **Submit**.

You choose one of three levels when you allow it:

- **Notes only:** read projects and notes, change a note's status and write internal notes.
- **Notes and projects:** also set up projects, review links, your clients' invitations and rounds, and reply to clients.
- **The whole workspace:** also brands, workspace settings and your team's invitations.

You can disconnect Antigravity at any time under **Settings**, **AI agents** in ClickNote.

## Things to ask

- "Which notes are still open on my ClickNote projects?"
- "Read ClickNote note 3 and find the file that element comes from."
- "Fix the copy notes on the home page, mark each one done and add an internal note saying what you changed."

## What it can never do

It can never change how anyone signs in (passwords, two-factor, keys, connected apps), your billing or plan, or delete a project, a brand or the workspace. Those stay in the ClickNote dashboard.
